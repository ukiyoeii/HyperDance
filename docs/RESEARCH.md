# 研究记录

目标是 AIST++ 十舞种，以及 Breaking 的 Toprock / Footwork / Powermove。网站目前仅部署后者。

## 数据与评估

AIST++ 每个舞种三名舞者，目前训练、验证、测试各一名；训练三个机位，验证一个机位。BRACE 按视频分组，允许舞者跨组，因此两项任务泛化指标不可直接比较。

处理后训练 / 验证 / 测试窗口：AIST++ 7035 / 1274 / 1298，BRACE 7713 / 845 / 750。所有已发布指标均来自验证集，**测试集尚未评估**。种子 42，单次实验。

## 模型与实验

MMAction2 ST-GCN，COCO 17 点骨架，x、y、置信度三通道。AIST++ 为 4 秒 120 帧，BRACE 为 2 秒 60 帧。batch 32，训练 drop_last=True，验证不丢最后批次，按验证平均类别准确率选择权重。

V1 AIST++ 最佳第 52 轮，BRACE 最佳第 10 轮。BRACE 窗口召回率 Toprock 97.89%、Footwork 66.22%、Powermove 81.41%，来源级总准确率 92%。来源级结果不能当作网站逐时刻准确率。

V2 A 同时增加缩放和单调时间扰动，窗口平均类别准确率 74.22% → 73.26%，Popping 未改善，Breaking 召回率 72.28% → 66.34%。组合实验无法归因于单项增强。

V2 B 拼接显式运动特征为六通道，窗口平均类别准确率 81.84% → 82.04%。Footwork 提高、Powermove 下降，两类间错误总数 146 → 144。单种子下没有明确的整体提升证据，因此网站保留 V1。

## 诊断与限制

Popping 训练召回率 100%，验证仅 6.98%，与训练舞者过拟合相符，但无法确定唯一原因。Footwork / Powermove 训练和验证均混淆，仍需人工检查混合动作、姿态质量和窗口时长，不能断言两类本质不可区分。

部署导出使用 30 个验证窗口核对，ONNX / PyTorch 类别一致 30/30，最大 logits 绝对误差约 9.06e-6。这是数值一致性验证，不是独立准确率评估。网站端到端实际效果还需要更多不同舞者真实视频验证。
